# Legacy Routes (Non-Core)

These routes are supported for compatibility only and are **not** part of the
four CLAW v1 core utilities. Do not expand their authority or scope.

## /v1/clauses/extract
Purpose: Optional clause extraction endpoint for legacy CLI flows.  
Status: Supported for compatibility; not part of v1 core utilities.

## /v1/agent_flow/* (if enabled)
Purpose: Experimental/legacy agent flow endpoints.  
Status: Supported for compatibility; not part of v1 core utilities.

Removal requires a separate PR and an explicit migration plan.
