# CLAW v1 Glossary

- **Timeline:** A sequence of evidence events with a deterministic manifest hash.
- **Freeze:** A step that seals a manifest hash and stops mutation.
- **Receipt:** A record that links a frozen manifest to an anchor (local by default).
- **Bundle:** A portable directory or zip containing artifacts and manifests.
- **Verifier:** A file-based tool that recomputes hashes and reports PASS/FAIL.
- **Attestation:** A signed statement recorded as an evidence artifact.
- **Agreement:** Drafted text with optional redlines, exported as JSON/Markdown.
