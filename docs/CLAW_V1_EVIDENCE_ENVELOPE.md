# CLAW v1 Evidence Envelope

## Canonical Definition
The CLAW v1 Evidence Envelope is a deterministic, verifiable object that binds a timeline reference with one or more attestations, and optionally an agreement reference, into a single evidence record. It is evidence‑only and does not imply legal enforceability, advice, or jurisdiction.

## Included Primitives
An evidence envelope includes:
- **Timeline reference** (timeline id and frozen manifest commitment)
- **Attestation(s)** (e‑sign and/or personal liability)
- **Agreement reference (optional)** (non‑enforcing, reference only)

## Non‑Goals
- No enforcement or adjudication
- No legal advice or legal conclusions
- No jurisdictional authority
- No network dependency for verification

This document freezes the CLAW v1 Evidence Envelope definition. If any document or implementation conflicts with this definition, the CLAW v1 Canon controls.
