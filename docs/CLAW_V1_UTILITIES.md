# CLAW v1 Utilities (Canonical)

This document defines the four canonical CLAW v1 user-facing utilities.
These definitions are normative for scope and interpretation.
Implementation details live elsewhere.

## 1. E-Sign Utility
Purpose:
- Capture user intent through cryptographically verifiable attestations.
- Bind identity, time, and declared capacity to an action.

Scope:
- User acknowledgements
- Signatures
- Assent to clauses, timelines, and determinations

## 2. Timeline Utility
Purpose:
- Create an ordered, immutable sequence of events and attestations.
- Serve as the primary evidentiary record for adjudication.

Scope:
- Event creation
- Event freezing
- Anchored receipts

## 3. Personal Liability Utility
Purpose:
- Allow users to declare attributes relevant to legal exposure.
- Identify potential liability surfaces without providing legal advice.
- Produce attestations suitable for later adjudication.

Scope:
- User-provided classifications
- Exposure flags
- Time-bound declarations

## 4. Agreements Utility
Purpose:
- Define conditional determinations and adjudication logic.
- Enable automated or semi-automated resolution paths.

Scope:
- Determination clauses
- Condition evaluation
- Outcome recording

No utility may exceed its defined scope.
