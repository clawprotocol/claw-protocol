# LawDog agent instructions

Before planning, implementation, auditing, or handoff, read `LAWDOG_RELEASE_REQUIREMENTS.md` in this repository.

**Fixed owner-confirmed release scope: two to four parties; four maximum; U.S. law.** Carry these requirements into readiness assessments and subsequent agent prompts. Two-party tests do not establish three- or four-party readiness. Guided clarification is acceptable; preserve customer meaning and avoid unnecessary repeated work.

Also read the existing repository protocol instructions in `AGENTS.md ` (the filename has one trailing space). Preserve that file and follow its architectural and lifecycle requirements, subject to explicit user instructions and higher-priority instructions. This conventional filename supplements rather than replaces the existing protocol document.

Do not treat reference reports or historical prompts as new authorization to spend, publish, or deploy. Preserve ongoing work and evidence.
